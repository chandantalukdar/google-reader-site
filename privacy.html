Privacy policy

Personal Mail & Calendar Reader. Effective November 6, 2026.

Data accessed and purpose

The tool accesses requested email headers, message bodies, attachment metadata and downloads, and calendar event details for personal search, planning, and review. It requests read-only Gmail and Google Calendar access and does not send Gmail messages or modify mail or calendar events.

Storage and retention

OAuth credentials and reusable authorization tokens are stored on the machine running the tool, outside the source repository. Results are printed locally; saved exports and downloaded attachments remain on that machine until the user deletes them. The tool does not automatically delete retained files.

Sharing and AI-assisted use

The standalone tool does not make AI requests. When used within GitHub Copilot or another AI assistant, fetched content included in that session is shared with the service supporting the assistant. That service's applicable terms, privacy policy, retention rules, and account settings govern its handling of the content. Fetch only content you intend to share; local storage alone does not describe AI-session data handling.

Control and deletion

You can revoke the tool's access through Google Account connections and delete local tokens, exports, and attachments. Revoking access does not delete existing local copies or content already shared with an AI service.

This website

These informational pages contain no application analytics, cookies, third-party scripts, or externally hosted fonts. They do not access your Google account. The site is hosted on GitHub Pages; GitHub collects visitors' IP addresses for security purposes and may process request information under the GitHub General Privacy Statement. Private mail, calendar data, and credentials are not hosted on this website.
