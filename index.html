Personal Mail & Calendar Reader

A command-line tool that helps its owner find Gmail messages and view upcoming Google Calendar events without changing mail or calendar data.

How it works

  • Search Gmail and read matching message headers and bodies.
  • View upcoming events from a selected Google Calendar.
  • Download attachments from a selected message when requested.

Authorization takes place through Google's sign-in and consent screens. The tool requests gmail.readonly and calendar.readonly access. It cannot send Gmail messages, mark them as read, delete mail, or create or edit calendar events.

These permissions cover the authorized account's accessible mail and calendars. Search queries and calendar selection limit what is fetched; they do not narrow the underlying account-level authorization.

This website only describes the tool. It does not connect to your Google account, display private records, or run the command-line application.
